# Стоп Обман

Статический сайт для GitHub Pages об интернет- и офлайн-мошенничестве. Проект сделан без backend и без сборщика: достаточно HTML, CSS и JavaScript.

## Структура

```text
.
├── index.html              # Главная страница
├── scheme.html             # Шаблон страницы одной схемы
├── assets/
│   ├── css/styles.css      # Стили сайта
│   ├── data/scams.js       # Данные по 15 схемам
│   ├── images/             # Картинки для карточек и страниц
│   └── js/                 # Скрипты главной и детальной страниц
└── README.md
```

## Как запустить локально

Откройте `index.html` в браузере или запустите простой локальный сервер из папки проекта:

```bash
python -m http.server 8080
```

После этого откройте:

```text
http://localhost:8080
```

Локальный сервер предпочтительнее, потому что страницы используют JavaScript-модули.

## Как собрать проект

Сборка не нужна. Это готовый статический сайт. Все файлы из корня проекта можно публиковать как есть.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта.
2. Откройте `Settings` -> `Pages`.
3. В блоке `Build and deployment` выберите `Deploy from a branch`.
4. Укажите ветку `main` и папку `/root`.
5. Сохраните настройки и дождитесь публикации.

Если используете собственный домен, добавьте его в настройках Pages. При необходимости создайте файл `CNAME` в корне проекта и укажите в нем домен, например:

```text
example.com
```

## Куда положить картинки

Картинки лежат в папке:

```text
assets/images/
```

Для замены изображения у конкретной схемы:

1. Поместите новый файл в `assets/images/`.
2. Откройте `assets/data/scams.js`.
3. Измените поле `image`, например:

```js
image: "assets/images/my-real-image.jpg"
```

4. Обновите `imageAlt`, чтобы описание картинки было понятным.

## Где редактировать тексты

Все данные находятся в файле:

```text
assets/data/scams.js
```

У каждой схемы есть поля:

- `slug` — идентификатор в ссылке, лучше писать латиницей без пробелов;
- `title` — название схемы;
- `shortDescription` — короткое описание для карточки;
- `image` — путь к картинке;
- `imageAlt` — текстовое описание картинки;
- `fullText` — полный текст материала;
- `howToRecognize` — список признаков обмана;
- `whatToDo` — список действий при столкновении со схемой.

Ссылка на страницу схемы формируется так:

```text
scheme.html?id=bank-security-call
```

где `bank-security-call` — значение поля `slug`.
